# ✈️ Aircraft Inventory Management System

A Python-based CRUD application designed to manage aircraft inventories, tracking aircraft details, maintenance statuses, and serial numbers with relational data persistence using **SQLite3**.

---

### 🚀 Key Features

- **Aircraft Registration & Management:** Full CRUD operations (Create, Read, Update, Delete) for managing aircraft records.
- **Relational Data Persistence:** Direct SQL queries and table creation using Python's native `sqlite3` module.
- **Inventory Auditing:** Querying aircraft status, availability, and specific technical specifications.
- **Data Validation & CLI Interface:** User input validation and error handling via terminal commands.

---

### 🛠️ Tech Stack

- **Language:** Python 3.10+
- **Database:** SQLite3 (Native Python Module)
